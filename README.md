# Трекер расходов

Учебный консольный проект на Python: помогает записывать повседневные расходы и смотреть сводку за текущий месяц.

## Что умеет программа

- Добавлять расход с датой, категорией, суммой и комментарием.
- Сохранять записи между запусками в JSON-файл.
- Показывать все расходы.
- Подсчитывать месячный итог и группировать расходы по категориям.
- Проверять ввод суммы; принимает десятичную точку или запятую.

## Технологии

- Python 3.10+
- Стандартные модули Python: `json`, `datetime`, `pathlib`
- Формат хранения данных: JSON

Дополнительные библиотеки не требуются.

## Запуск

Откройте терминал в папке проекта и выполните:

```powershell
python main.py
```

Файл `expenses.json` создаётся автоматически после добавления первого расхода.

## Пример использования

1. Выберите `1` и добавьте расход, например категорию «Еда» и сумму `12,50`.
2. Выберите `2`, чтобы просмотреть сохранённые записи.
3. Выберите `3`, чтобы увидеть сумму расходов за текущий месяц по категориям.
4. Выберите `0`, чтобы завершить работу.

## Структура проекта

- `main.py` — меню приложения, обработка ввода, расчёт сводки и сохранение данных.
- `expenses.json` — пользовательские данные; файл создаётся при первом сохранении расхода.
- `expenses.example.json` — пример формата данных без личной информации.
